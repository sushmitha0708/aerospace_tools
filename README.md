# Aerospace Engineering Tools

A collection of aerospace engineering calculators and utilities.

## Current Tools

### ISA Atmosphere Calculator

The International Standard Atmosphere calculator provides:

- Temperature
- Pressure
- Density
- Speed of sound
- SI units
- FPS units
- ISA atmosphere plots
- Selected-altitude visualization

### Technology

- Python
- PySide6
- NumPy
- Matplotlib
